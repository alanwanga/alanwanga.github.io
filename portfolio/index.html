02

TAnGY: Gemini-Planned Multi-Drone Delivery in Simulation

PoC → Independent R&D
MuJoCo Gemini Robotics-ER Simplex Safety Multi-Agent Planning Evaluation

Physics-simulated multi-drone delivery coordinator (PoC) — Gemini proposes plans, deterministic code decides what may fly, and failures escalate to a human whose replies pass the same checks.

Original PoC demo (Three.js + Flask), before the MuJoCo rebuild

Problem

Vision-language and reasoning models can translate open-ended mission descriptions into multi-drone task plans, but in a safety-critical airspace setting, a hallucinated or unsafe plan must never reach flight execution.

My Role

Co-built the original PoC (Three.js + Flask); independently rebuilt it end to end in MuJoCo with quadrotor physics, pixel-based perception, a deterministic Simplex safety layer, and an automated evaluation benchmark.

Technical Work

  • Simplex architecture: Gemini turns mission text and scene tracks into a task graph; deterministic code assigns drones, times trajectories, and checks geofence, altitude, no-fly zones, separation, and battery — routing violations back to Gemini (up to 3 rounds) and then to a human operator under the same checks.
  • Perception from pixels: Gemini Robotics-ER points at objects in simulated RGB-D camera frames; points are back-projected with depth and tracked via a Kalman filter with Hungarian association (recall 0.80–0.82 at precision 0.95–0.96).
  • Flight control & onboard monitor: geometric SE(3) controller settles a 1 m step in 1.6 s and holds hover within 1 cm under a 2 N side wind; an independent onboard monitor runs every tick to land the drone without relying on cloud connectivity.
  • Independent ground-truth audit: a 50 Hz auditor sharing zero code with the planner checker scores safety violations against simulator state, and every model stage is benchmarked against an oracle baseline.
  • (Original PoC) Text descriptions generate custom 3D test scenes.
  • (Original PoC) Logs commands, reasoning, actions, and feedback as episodes for a reinforcement-learning dataset.

Impact

  • 0 safety violations across 300 adversarial plans, 8 adversarial physics episodes, and 240 benchmark runs.
  • 20/20 end-to-end simulated missions (live Gemini calls) delivered the payload to the right target; on a 10-task benchmark suite (3 runs per task), Gemini Robotics-ER planning improved from 12/30 to 30/30 once the planner saw the scene (annotated scout image, own drones masked, targets described by color).

Safety-Critical Configuration & Authorization

Wing
Authorization RBAC Spanner Distributed Configuration Migration

Authorization for human-in-the-loop operations — re-architected access control so every RPC, including emergency landing, checks who may issue it, moving from database-persisted roles mirrored into an ACL service to config-driven RBAC.

Problem

The legacy authorization flow persisted per-organization roles in the database and synced them asynchronously into a Zanzibar-based group-membership service. The sync could drift, and adding a role required handler changes, a backfill, and a re-sync — all while live airspace operations could not be interrupted.

My Role

Eng lead and co-author of the redesign; led the role-configuration schema, validation, and phased migration plan.

Technical Work

  • Decomposed the monolith into three services: Organization, User, and Member License Management.
  • Replaced per-organization database roles with a global, schema-validated configuration mapping roles to permissions, with per-RPC permission annotations.
  • Implemented deny-by-default per-RPC permission checks (one keyed Spanner membership read plus an in-memory lookup), including safety-critical commands such as pilot-issued emergency landing, shipping configuration before code.

Impact

  • Retired the database-to-ACL sync dependency across live safety-critical services via a flag-guarded, multi-quarter migration.
  • Turned adding or updating a role into a reviewed configuration change instead of handler code changes, a database backfill, and an ACL re-sync.
